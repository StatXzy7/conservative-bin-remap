# conservative-bin-remap

Python 区间重分箱（re-binning）计算引擎：把不同仪器在互不重叠的一维源区间上
测得的累计量与方差，换算到调用者给定的目标区间上，并给出完整协方差、未覆盖
部分统计和每组守恒误差诊断。纯 Python 标准库实现，**零第三方依赖**，可在
Linux x86_64 / Python 3.11 上直接运行，不依赖任何外部服务。

## 模型

- 源区间互不重叠（边界可以恰好接触），每个源区间内部假定**密度均匀**，因此
  总量按重叠长度线性分配：源 `i` 落入目标 `j` 的比例
  `f[j,i] = overlap(target_j, source_i) / width(source_i)`。
- 各源区间的测量相互独立，方差为 `Var_i`。拆分后的片段是同一测量的线性函数，
  因此彼此相关：`Cov(Y_j, Y_k) = sum_i f[j,i] f[k,i] Var_i`。
- 区间按半开区间 `[lo, hi)` 处理，恰好接触的公共边重叠长度为 0，不会重复分配。
- 目标区间可以有间隙，也可以只覆盖部分源范围。未覆盖部分
  `U = sum_i (1 - sum_j f[j,i]) X_i`，其总量、方差及与每个目标区间的协方差
  一并返回。目标区间完全在源范围之外时得到零，不报错。

## 接口

```python
from rebin import remap

result = remap(source_edges, target_edges, totals, variances)
```

- `source_edges` / `target_edges`：`[(lo, hi), ...]`，实数对，`lo < hi`，
  互不重叠；输入顺序任意，**目标输出顺序严格保持调用者给定顺序**。
- `totals` / `variances`：一维序列表示单组测量；二维序列（组在前）表示多组
  测量共用同一套区间边界。零总量、零方差是合法输入。
- 返回 `RebinResult`：
  - `groups[g].target_totals`：每个目标区间的总量（目标顺序）。
  - `groups[g].target_cov`：目标区间之间的完整 `m x m` 协方差矩阵（对称）。
  - `groups[g].uncovered_total` / `uncovered_variance`：未覆盖部分的总量与方差。
  - `groups[g].uncovered_cov[j]`：未覆盖部分与目标 `j` 的协方差。
  - `diagnostics[g]`：该组输入/合并输出的总量、方差及残差
    （`total_error`、`variance_error`），即守恒误差诊断。

非法输入（负总量、负方差、NaN/Inf、零宽或反向区间、源/目标重叠、维度不一致、
空区间、错误的二元组形状）抛出 `rebin.RemapError`；失败或成功都不会修改调用者
传入的数据（内部全部先复制再校验）。

## 守恒性质（精确算术下成立）

`sum_j Y_j + U = sum_i X_i`；把所有输出与未覆盖部分重新合并（计入全部协方差）
后总方差等于 `sum_i Var_i`。浮点残差见每个组的 `diagnostics`。

## 精度约定

- 全部计算使用 Python `float`（IEEE-754 binary64）。
- 比例按 `重叠长度 / 源宽度` 直接计算；总量与方差的求和使用 `math.fsum`
  （成对精确求和后一次舍入），以抑制多段累加误差。
- 协方差矩阵按构造严格对称（只计算上三角并镜像）。
- 不做静默截断或“钳零”：当比例无法被二进制精确表示（如 1/3）或浮点边界切分
  使比例之和偏离 1 几个 ulp 时，未覆盖量可能出现约 `1e-16` 量级的小残差
  （正或负）。残差如实记录在 `diagnostics` 中；典型绝对守恒误差在
  `1e-14 ~ 1e-11` 量级，随区间数量缓慢增长。需要严格非负的下游使用方可按
  自身容差处理。
- 输入边界与数值必须有限。

## 为什么“任意重新分箱再还原”不保证恢复原分布

重分箱在每个源区间内采用**均匀密度**假设，只保留每段总量这一个标量，丢弃了
区间内部的密度形状信息。它是线性投影，一般不可逆。

反例：总量 10 实际集中在 `[0,2)` 左边缘。先映射到 `[0,1)`、`[1,2)` 两个目标
箱时，均匀假设给出 `[5, 5]`；再按原箱合并只能拿回总量 10，永远无法还原“集中
在左边缘”的事实。任何与该投影得到的均匀分布具有相同逐箱总量的其他分布，
重分箱结果完全相同。总量与（含协方差的）方差可以守恒，但分布本身不能。

## 命令行演示

包含手算小例子、多组测量、拆分后非零协方差、合并守恒断言和非可逆性演示：

```bash
python demo.py
```

演示会打印输入、操作、结果和逐项断言；任何断言失败以非零状态退出。

## 测试

```bash
python -m unittest discover -s tests -v
```

`tests/common.py` 用 `fractions.Fraction` 提供一份独立编写的精确参考实现，
测试把引擎结果与精确分数结果逐项对照，并覆盖：主流程全覆盖、部分覆盖与间隙、
拆分非零协方差、合并守恒、多组共用边界、乱序输入与目标顺序保持、边界接触不
重复分配、失败不改变输入，以及全部非法边界拒绝用例。

## 项目结构

- `rebin/engine.py`：核心引擎（校验、重叠比例、协方差传播、守恒诊断）。
- `demo.py`：命令行演示。
- `tests/`：unittest 测试与精确参考实现。
- `atk-demo.json`：自动化演示配置（terminal，直接运行 `demo.py`）。
